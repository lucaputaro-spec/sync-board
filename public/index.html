How it works

Cut the connection. Keep editing.
Come back to the same board.

A shared note board that keeps working without a network. Every open copy edits on its own, and once the copies can talk again they merge into the same result, with no server picking a winner. The merge logic is written from scratch, not imported.

Two boards, one shared state

These are two separate copies of one board, each with its own live connection, like two people on two laptops. Switch both to offline, type into the same note on each side, then switch them back on.

Unsent changes live only in the open tab. If you close a tab while it is offline, its unsent changes are gone. The browser asks first.

How it works

Text merges character by character.
Every character gets a permanent ID and remembers which character it was typed after. When two people type at the same spot, both words stay, whole and in the same order on every device. The technique is called RGA, a sequence CRDT.
Position and color: the last writer wins.
A note cannot sit in two places. Each move carries a logical timestamp, and every device keeps the one with the highest stamp. Same rule everywhere, so the same winner everywhere.
The server stores and forwards. It never decides.
A Cloudflare Durable Object keeps an append-only log per board and relays it over WebSockets. Order of arrival does not matter, duplicates do not matter. The data structure does the merging, not the server.
Tested with random chaos, not just examples.
The test suite plays 2,000 random schedules against the merge logic and 400 more through the sync layer: changes out of order, twice, late, with dropped connections. All copies must end up identical, and no typed character may go missing unless someone deleted it. The random seed is fixed, so any failure can be replayed.
Hard limits against abuse.
A board expires after 24 hours. It holds at most 24 notes, and every note has a size cap. If two copies go over a limit together while offline, the server refuses the later one. That copy says how many changes it discarded, shows its text for copying, and reloads from the server. Nothing is stored in your browser. There are no accounts and no cookies.
What it does not do.
Deleting a note beats edits made to it at the same time. Nothing is saved in your browser, so closing the tab while offline drops unsent changes. The page warns you first. Going over a limit offline discards the later copy's changes, as described above. These are deliberate trade-offs for a demo this size.
